INTRODUCTION TO PROGRAMMING

Mengenal JavaScript

JavaScript merupakan bahasa pemrograman yang banyak digunakan dalam pengembangan website. Bahasa ini memungkinkan sebuah halaman web memiliki fitur dan interaksi yang dinamis.

Jika HTML digunakan untuk menyusun struktur dan CSS digunakan untuk mengatur tampilan, JavaScript berperan dalam mengatur perilaku dan interaksi pada halaman website.

Dengan JavaScript, pengembang dapat membuat tombol interaktif, validasi formulir, perubahan konten, menu dinamis, dan berbagai fitur lainnya.

Apa yang Bisa Dilakukan JavaScript?

Interaksi Pengguna

Membuat tombol, menu, dan elemen website merespons tindakan pengguna.

Pengolahan Data

Mengolah informasi menggunakan variabel, operator, dan fungsi.

Validasi Formulir

Memeriksa masukan pengguna sebelum data diproses lebih lanjut.

Konten Dinamis

Mengubah teks, gambar, dan tampilan halaman tanpa harus memuat ulang seluruhnya.

Materi yang Akan Dipelajari

Pembelajaran dimulai dari konsep pemrograman dasar hingga membuat fitur interaktif sederhana.

01. Pengenalan JavaScript

Mengenal pengertian, fungsi, karakteristik, dan cara kerja JavaScript dalam sebuah website.

02. Variabel dan Tipe Data

Mempelajari cara menyimpan informasi menggunakan let, const, serta mengenal tipe data seperti string, number, boolean, dan lainnya.

03. Operator

Mengenal operator aritmatika, perbandingan, penugasan, dan logika untuk mengolah data.

04. Percabangan

Menggunakan if, else if, else, dan switch untuk menentukan tindakan berdasarkan suatu kondisi.

05. Perulangan

Mempelajari for, while, dan do while untuk menjalankan instruksi secara berulang sesuai kondisi.

06. Function

Memahami cara membuat fungsi, memberikan parameter, dan mengembalikan nilai menggunakan return.

07. DOM (Document Object Model)

Mempelajari cara mengakses dan mengubah elemen HTML menggunakan JavaScript.

08. Event dan Interaksi

Mengenal event seperti click, input, dan submit untuk membuat halaman web lebih interaktif.

Tujuan Pembelajaran

Memahami Logika

Melatih kemampuan berpikir logis dalam menyelesaikan permasalahan.

Mengolah Data

Mampu menggunakan variabel, tipe data, dan operator.

Menguasai Dasar JavaScript

Mampu menggunakan kondisi, perulangan, dan fungsi.

Membuat Website Interaktif

Mampu menambahkan fitur sederhana pada halaman website.

Tools yang Digunakan

Beberapa perangkat yang dapat digunakan untuk belajar dan menulis kode JavaScript:

  • Acode — editor kode untuk perangkat Android.
  • Visual Studio Code — editor kode untuk komputer.
  • Google Chrome — menjalankan dan menguji website.
  • Browser Developer Tools — memeriksa kode dan error.

Contoh Penerapan JavaScript

JavaScript digunakan untuk membuat berbagai fitur yang sering ditemukan pada website.

  • Validasi halaman login dan registrasi.
  • Kalkulator sederhana.
  • Keranjang belanja online.
  • Menu interaktif dan dropdown.
  • Galeri gambar interaktif.
  • Penghitung nilai atau skor.

Project Ideas

Setelah memahami materi, siswa dapat mencoba membuat proyek sederhana seperti:

  • Simple Calculator — aplikasi kalkulator.
  • To-Do List — aplikasi daftar kegiatan.
  • Digital Clock — jam digital sederhana.
  • Quiz App — aplikasi kuis interaktif.
  • Shopping Cart — keranjang belanja sederhana.
