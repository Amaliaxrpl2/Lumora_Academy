INTRODUCTION TO WEB DEVELOPMENT

Mengenal HTML & CSS

HTML dan CSS merupakan dua teknologi dasar yang digunakan dalam pembuatan website. Keduanya memiliki fungsi yang berbeda, tetapi saling melengkapi untuk menghasilkan halaman web yang menarik dan mudah digunakan.

HTML berfungsi untuk membangun struktur dan menyusun isi halaman website. Sementara itu, CSS digunakan untuk mengatur tampilan visual seperti warna, ukuran teks, jarak, tata letak, dan desain halaman.

Dua Teknologi, Dua Peran

HTML

HyperText Markup Language merupakan bahasa markup yang digunakan untuk menyusun struktur halaman website.

Contohnya adalah membuat judul, paragraf, gambar, tautan, daftar, tabel, dan formulir.

CSS

Cascading Style Sheets merupakan bahasa stylesheet yang digunakan untuk mengatur tampilan halaman website.

Contohnya adalah mengatur warna, jenis huruf, ukuran teks, background, posisi elemen, dan animasi sederhana.

Materi yang Akan Dipelajari

Pembelajaran dimulai dari konsep paling dasar hingga membuat halaman website sederhana.

01. Dasar-Dasar HTML

Mengenal struktur dasar dokumen HTML, penggunaan tag, elemen, dan atribut.

Materi meliputi heading, paragraf, gambar, tautan, daftar, dan tabel.

02. Struktur dan Elemen HTML

Memahami bagian-bagian halaman website seperti header, main, section, article, dan footer.

03. Dasar-Dasar CSS

Mengenal selector, property, value, serta cara menghubungkan CSS dengan dokumen HTML.

04. Styling dan Layout

Mempelajari warna, background, font, border, margin, padding, display, flexbox, dan grid.

05. Responsive Web Design

Membuat website yang dapat menyesuaikan tampilannya pada berbagai ukuran layar, mulai dari HP hingga komputer.

06. Menggabungkan HTML dan CSS

Menggabungkan struktur HTML dengan desain CSS untuk menghasilkan halaman website yang utuh.

Tujuan Pembelajaran

Memahami Struktur Web

Mengetahui cara kerja dan susunan dasar sebuah halaman website.

Menguasai Dasar HTML

Mampu membuat struktur halaman menggunakan elemen HTML.

Menguasai Dasar CSS

Mampu mengatur desain dan tampilan website menggunakan CSS.

Membuat Website

Mampu mengembangkan halaman web sederhana secara mandiri.

Contoh Penerapan dalam Kehidupan Nyata

HTML dan CSS digunakan dalam berbagai jenis website yang sering kita temui sehari-hari.

  • Website profil pribadi dan portofolio.
  • Website informasi sekolah.
  • Website katalog produk dan toko online.
  • Website berita dan artikel.
  • Website pembelajaran dan pendidikan.

Project Ideas

Untuk mengasah kemampuan, siswa dapat mencoba membuat beberapa proyek berikut:

  • Personal Profile Website — website tentang diri sendiri.
  • School Website — halaman informasi sekolah.
  • Product Catalog — katalog produk sederhana.
  • Landing Page — halaman promosi suatu produk.
  • Portfolio Website — tempat menampilkan hasil karya.
